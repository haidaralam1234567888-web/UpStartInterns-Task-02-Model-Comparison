# UpStartInterns Task 02: Train and Compare Models

## Objective

Train and compare three machine learning algorithms on the Iris dataset.

## Dataset

The Iris dataset contains 150 samples, four numerical features, and three flower classes.

## Models

* Logistic Regression
* Decision Tree
* Random Forest

## Methodology

* Used an 80/20 train-test split.
* Used the same split for all three models.
* Evaluated Accuracy, Precision, Recall, and F1-score.

## Results

| Model               | Accuracy | F1-score |
| ------------------- | -------: | -------: |
| Logistic Regression |   96.67% |   96.66% |
| Decision Tree       |   93.33% |   93.33% |
| Random Forest       |   90.00% |   89.97% |

## Conclusion

Logistic Regression achieved the highest accuracy on the selected test set.
